## Deutsch

**Notater Skriver** ist ein schlanker, hochperformanter Web-Texteditor, der für maximale Effizienz im Browser entwickelt wurde. Die Anwendung ist ab sofort vollständig für den mobilen Einsatz auf Smartphones und Tablets optimiert.

### Systemarchitektur und Design
Die Anwendung setzt auf eine moderne, minimalistische Benutzeroberfläche. Durch neue, elegante Hintergrundoptionen lässt sich der Fokus gezielt auf den Schreibprozess lenken, unabhängig von der Bildschirmgröße.

1. **Dashboard:** Das zentrale Verwaltungszentrum.
   * **Schnelleinstieg:** Sofortige Erstellung neuer Dokumente.
   * **Übersicht:** Verwaltung der zuletzt bearbeiteten Dateien inkl. Zeitstempel.
   * **Notater News:** Zentrale Informationsquelle für Updates, Barrierefreiheit und technische Changelogs.
* Beispiel des Dashboards im "Slate-Design".

2. **Bearbeitungsansicht:** Eine voll ausgestattete Editor-Umgebung. Die responsive Architektur garantiert, dass die Werkzeugleiste sowohl auf Desktop-Systemen als auch auf mobilen Endgeräten präzise bedienbar bleibt.
* Bespiel der Bearbeitungsansicht im "Slate-Design".

### Datensicherheit und Speicher
Die Anwendung nutzt **IndexedDB** zur lokalen Speicherung. Ihre Daten verlassen zu keinem Zeitpunkt das Gerät und bleiben lokal auf Ihrem Browser-Speicher gesichert – eine externe Datenbank ist nicht erforderlich.

### Funktionsübersicht
Die Oberfläche ist in logische Reiter gegliedert:
* **Start:** Zentrale Formatierung (Schrift, Farbe, Stil, Ausrichtung).
* **Einfügen:** Tabellen, Listen und strukturierte Trennelemente.
* **Format:** Layout-Anpassungen, Zeilenabstände und Seitenränder.
* **Tools:** Such- und Ersetzungs-Algorithmen.
* **Export:** Unterstützung für PDF, .docx (Neu), HTML und .txt.
* **Katalog:** Integriertes Benutzerhandbuch für den schnellen Zugriff auf Funktionen.
* **Ansicht:** Anpassbare UI-Modi und Fokus-Optionen.

### Leistung und Benutzerführung
* **Echtzeit-Statistiken:** Die Statusleiste überwacht kontinuierlich Wortanzahl, Zeichen und Lesezeit.
* **Präzisions-Editing:** Hoch- und tiefgestellte Zeichen für wissenschaftliche Notationen sind nativ integriert.
* **Workflow:** Volle Unterstützung von Standard-Tastenkombinationen für effizientes Arbeiten.

## English

**Notater Skriver** is a lightweight, high-performance web-based text editor designed for maximum efficiency within the browser. The application is now fully optimized for mobile use on smartphones and tablets.

### System Architecture and Design
The application features a modern, minimalist user interface. New, elegant background options allow users to focus entirely on the writing process, regardless of screen size.

1. **Dashboard:** The central management hub. 
* **Quick Start:** Create new documents instantly. 
* **Overview:** Manage recently edited files, complete with timestamps. 
* **Notater News:** A central source for updates, accessibility information, and technical changelogs.
* Example of the dashboard in the "Slate" design. 
<img width="1595" height="896" alt="Dashboard in the 'Slate' design" src="https://github.com/user-attachments/assets/ba85c2b6-decc-4151-89ea-e48f21bc28fc" />

2. **Editing View:** A fully-featured editor environment. Its responsive architecture ensures that the toolbar remains easy to use and precise, whether on a desktop system or a mobile device.
* Example of the editing view in the "Slate" design. <img width="1599" height="898" alt="Editing view in 'Slate' design" src="https://github.com/user-attachments/assets/3ef92ce8-ba86-4bba-b093-3e1f76f0ab42" />

### Data Security and Storage
The application uses **IndexedDB** for local storage. Your data never leaves your device and remains stored locally within your browser—no external database is required.

### Feature Overview
The interface is organized into logical tabs:
* **Home:** Core formatting (font, color, style, alignment).
* **Insert:** Tables, lists, and structured separators.
* **Format:** Layout adjustments, line spacing, and page margins.
* **Tools:** Search and replace algorithms.
* **Export:** Support for PDF, .docx (new), HTML, and .txt.
* **Catalog:** An integrated user manual for quick access to features.
* **View:** Customizable UI modes and focus options.

### Performance and User Experience
* **Real-time Statistics:** The status bar continuously tracks word count, character count, and reading time.
* **Precision Editing:** Native support for superscript and subscript characters, ideal for scientific notation.
* **Workflow:** Full support for standard keyboard shortcuts to ensure an efficient workflow.
